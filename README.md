# AI Stage 2: Data and Machine Learning

This repository documents my Stage 2 journey into data and machine learning.

The goal is to learn how to work with real datasets, train machine learning models, evaluate them correctly, and understand their limitations.

## Main Topics

- Data cleaning and preprocessing
- Feature engineering
- Regression and classification
- Model training and validation
- Overfitting and underfitting
- Evaluation metrics
- Decision trees and ensemble models
- Unsupervised learning
- Recommendation systems

## Tools

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Projects

- Prediction system
- Classification system
- Fraud detection system
- Recommendation system

## Goal

By the end of this stage, I should be able to take a real dataset, build and evaluate a machine learning model, explain how it works, and understand where it can fail.
